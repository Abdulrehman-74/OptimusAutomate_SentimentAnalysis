# OptimusAutomate_SentimentAnalysis
# Sentiment Analysis on Product Reviews

## Machine Learning Internship Project

This project was completed as part of the Machine Learning Virtual Internship Program by Optimus Automate.

## Project Objective

The objective of this project is to analyze customer product reviews and classify sentiments as Positive, Neutral, or Negative using Natural Language Processing (NLP) and Machine Learning techniques.

## Dataset

The dataset contains customer product reviews and ratings collected from online shopping platforms.

## Tasks Performed

* Data Loading and Exploration
* Text Cleaning
* Stopword Removal
* Sentiment Label Creation
* TF-IDF Vectorization
* Machine Learning Model Training
* Model Comparison
* Performance Evaluation
* Sentiment Visualization

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* NLTK
* Scikit-learn

## Machine Learning Models

* Multinomial Naive Bayes
* Support Vector Machine (SVM)

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score

## Visualizations

* Sentiment Distribution Chart
* Model Performance Comparison

## Project Outcome

The models successfully classified customer reviews into Positive, Neutral, and Negative sentiments. SVM and Naive Bayes models were compared to identify the best-performing classifier.
